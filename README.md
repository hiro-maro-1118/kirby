# ⭐ ぷぷぷ育成フレンズ（たまごっち風カービィ育成×テスト復習Webアプリ）

小学5年生向けのテスト復習ができる、レトロたまごっち風ドット絵カービィ育成Webアプリケーションです。  
問題を解いてごちそうを獲得し、ごはんによって蓄積される裏パラメータに応じて**「おむつ ➔ 普通 ➔ 単能力 ➔ 複合能力」**の4段階進化が楽しめます。

---

## 💻 ローカル環境での動かし方（PC）

```bash
npm run dev
# または
node serve.js
```
- **ゲーム画面**: `http://localhost:3000`
- **親用問題管理ダッシュボード**: `http://localhost:3000/admin.html`

---

## 🛠️ 親用問題管理ダッシュボード (`admin.html`)

PCやスマホのブラウザから `http://<IPアドレス>:8080/admin.html`（ローカル時は `http://localhost:3000/admin.html`）にアクセスすることで、快適なモダンUIで問題管理ができます。

- **3つの区分管理**:
  1. 📝 **「とりあえず作る」**: 通常の自作練習問題
  2. ⚠️ **「にがてな問題」**: 重点的に克服させたい問題
  3. 🚀 **「1学年上の問題」**: 先取り・応用チャレンジ問題
- **機能**:
  - 4形式（4択、穴埋め、数字入力、長文読解）の問題登録・編集・削除
  - 学年・教科フィルタ、キーワード検索
  - JSON一括エクスポート / インポート（バックアップ・共有対応）
  - 正答率・学習データレポートの分析

## 🎮 5問連続すいこみテスト形式

1回のテストで**5問連続で挑戦**します。
- 1問ごとに敵をすいこみ解答！
- 5問終了後に**「総合リザルト画面」**が表示され、正解数と獲得したごちそうアイテム一覧が手に入ります。
- 獲得したアイテムをお部屋でカービィにあげて育成しましょう！

### 1. リポジトリをNASに配置して起動
```bash
# コンテナのビルドとバックグラウンド起動
docker compose up -d --build
```
起動後、ブラウザで `http://<NASのIPアドレス>:8080` にアクセスするとプレイできます。

## 🧬 4段階進化ツリーと裏パラメータ仕様

`data/evolution_tree.json` で進化条件を自由に拡張・追加できます。

1. **第1形態：おむつカービィ (Baby)**
   - 初期状態。バブバブ動く赤ちゃん姿。
2. **第2形態：普通カービィ (Normal)**
   - 基礎経験値（EXP）が一定値を超えると進化。
3. **第3形態：単能力カービィ (Single)**
   - 食べたごはんの属性（炎・斬撃・雷・氷・知力）が30以上に達すると各能力へ進化！
   - 例：からくちカレー多 ➔ **ファイアカービィ**、まんが肉多 ➔ **ソードカービィ**
4. **第4形態：複合能力カービィ (Combo)**
   - 2つ以上の属性が掛け合わさることで究極合体！
   - 例：炎＋斬撃 ➔ **バーニングソード**、雷＋斬撃 ➔ **スパークブレード**、全属性 ➔ **スターロッド・レジェンド**

## 🎮 操作方法

- **Aボタン**（またはキーボード `Z`）: 決定 / お世話
- **Bボタン**（またはキーボード `X`）: もどる / ホーム
- **Cボタン**（またはキーボード `C`）: メニュー切り替え（お部屋 ➔ テスト ➔ ごはん ➔ ずかん ➔ レポート）
- **カービィを直接クリック/タップ**: なでなでしてごきげんUP！
